# Видеохостинг - Docker Deployment

Этот проект представляет собой видеохостинговое приложение, состоящее из фронтенда на React и бэкенда на Node.js с базой данных MySQL. Все компоненты упакованы в Docker-контейнеры для удобного развертывания.

## Структура проекта

- `React/` - содержит фронтенд на React
- `Server/` - содержит бэкенд на Node.js
- `docker-compose.yml` - файл для orchestration всех сервисов
- `.env` - файлы с переменными окружения

## Требования

- Docker
- Docker Compose

## Установка и запуск

1. Убедитесь, что Docker и Docker Compose установлены на вашей системе.

2. Склонируйте репозиторий и перейдите в директорию проекта.

3. Создайте файл `.env` в корне проекта с необходимыми переменными:

```
DB_USER=root
DB_PASSWORD=root
DB_NAME=video_hosting
SESSION_SECRET=your-super-secret-session-key-change-this-in-production
```

4. Запустите проект командой:

```bash
docker-compose up --build
```

После запуска приложение будет доступно по адресу:
- Frontend: http://localhost:3000
- Backend API: http://localhost:3001

## Архитектура

Проект состоит из трех основных сервисов:

1. **MySQL** - база данных для хранения информации о пользователях, видео и лайках
2. **Server** - Node.js сервер, обрабатывающий API запросы
3. **Client** - React приложение, предоставляющее пользовательский интерфейс

## Хранение данных

Данные базы данных хранятся в Docker volume `mysql_data`, что обеспечивает их сохранность между перезапусками контейнеров.

Видео файлы, загружаемые пользователями, хранятся в директории `Server/VideoFiles`, которая также монтируется в контейнер сервера.

## Инициализация базы данных

При первом запуске база данных инициализируется с помощью файла `Server/init.sql`, который создает необходимые таблицы:

- `Accounts` - информация о пользователях
- `videos` - информация о видео
- `likes` - информация о лайках
- `sessions` - сессии пользователей

## Настройка CORS

Сервер настроен для работы с фронтендом через CORS, разрешая запросы с домена http://localhost:3000.

## Порты

- 3000: React frontend (через nginx)
- 3001: Node.js backend
- 3306: MySQL (внутренний порт контейнера)

## Сборка

При изменении кода достаточно перезапустить соответствующий сервис с флагом `--build` для пересборки образа:

```bash
docker-compose up --build server
```

или

```bash
docker-compose up --build client
```
